## Overview

This folder contains a one-off web scraping project for collecting and analyzing Intel Xeon processor specifications.

---

## Files

### CPU Database Scraping Project (`cpu-db/`)

All files in this subfolder are related and form a complete web scraping pipeline:

| File | Description |
|------|-------------|
| [`proc.html`](cpu-db/proc.html) | Saved HTML page from cpu-world.com containing Intel Xeon processor comparison chart. This is the source data file. |
| [`scrape-cpu.py`](cpu-db/scrape-cpu.py) | Python script that parses the HTML table from `proc.html` using BeautifulSoup, converts it to a pandas DataFrame, and stores the data in a SQLite database. |
| [`cpu.db`](cpu-db/cpu.db) | SQLite database generated by `scrape-cpu.py` containing the parsed processor data. |
| [`cpu.sql`](cpu-db/cpu.sql) | SQL queries to filter and analyze the CPU data, specifically filtering for Socket 3647 Xeon processors with TDP ≤ 110W. |

### Dependencies

The `scrape-cpu.py` script requires:
- `beautifulsoup4` (with `lxml` parser)
- `pandas`
- `sqlalchemy`
- `requests` (imported but not used in current version)
- `codecs` (standard library)

### Data Flow

```
proc.html → scrape-cpu.py → cpu.db → cpu.sql (queries)
```

1. `proc.html` is downloaded/saved from cpu-world.com
2. `scrape-cpu.py` reads and parses the HTML table
3. Data is stored in `cpu.db` SQLite database
4. `cpu.sql` contains example queries to analyze the data
